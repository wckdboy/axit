before you swing

Clear boundaries.

What does Axit read?

The index stores file metadata and names. It does not index file contents, follow symlinks or scan other mounted filesystems. Access failures are counted and visible in Activity.

What can it clean?

Recognized generated caches with ownership, age, Git, activity and protected-content checks. Whole Rust target directories and release profiles are preserved. Trash and moves use a reviewed plan; permanent cache cleanup is clearly labeled.

Does it run automatically?

Automatic cleanup is off by default. Opt-in rules need explicit folders and apply age, size, free-space and cooldown limits. No background service is installed automatically.

What about macOS privacy permissions?

Grant your terminal Full Disk Access to include protected locations. Administrator access alone does not remove macOS privacy restrictions. Axit reports gaps in coverage.

I used SCRY. Is my index still here?

Yes. Axit reuses the previous private store when no Axit store exists, including the index, preferences and undo journal. Legacy configuration variables and MCP tool names remain accepted.

File mutations require lsof; scans and search work without it. Folder totals can overlap, and indexed sizes need refreshing after changes.
